# Q-68 widened — ADR-021 condition 2, 2026-10-15

One machine (the owner's Windows workstation), portable PostgreSQL 16 + PostGIS on port 55499, database `bench`.
Data: 927,350 OpenStreetMap polygons over Türkiye in EPSG:3857 (buildings and administrative boundaries).
Three tables derived from it by `q68-tables.sql`: the polygons, their boundaries as lines, and the polygons
with 24 more attributes (categories, names, numbers, one value unique to each feature).

Run: `GisBench q68 --table <t> --geom geom --attrs <list> --parents 4 --rounds 3 --child 14` (z12 → z14, 64 tiles a round).

## Corrected harness (2026-10-15, later): ST_AsMVT is given 'osm_id' as the feature id

Until this, path A wrote osm_id as an attribute of every feature (a value dictionary of 521 KB against 43 KB in one z12 parent's tiles), so the two paths answered different questions and their bytes diverged. With it, they agree.
