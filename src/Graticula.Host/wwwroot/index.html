Data sources

Databases and folders this server reads layers from. Only administrators register one, because a source holds the credentials to someone else's database.

NameConnectionLayers
What registering does

A PostGIS database this server reads from, or a folder of GeoParquet files it reads in place. Registering a database stores the credential, sealed, because the server connects again every time somebody opens a map on it; a folder stores only its path. Nothing is published by registering: you choose the tables or files afterwards, in Publish a service.

Map

What every new map in this organization starts on, and the basemaps it offers.

Basemap gallery

The group whose vector tile services (in Web Mercator) and web maps appear as basemaps in Map Viewer, ArcGIS Pro and Maps SDK apps, as an ArcGIS Enterprise basemap gallery does. Anybody who can share into the group can add one.

Default basemap

What a new map starts on.

Map ground

Your own vector tile services, such as an OpenStreetMap extract you imported, drawn under the data when the default basemap is Your own tile services. With none chosen, OpenStreetMap's public tiles are drawn. People who chose their own ground in the viewer keep it.

    Utility services

    Services this organization points its ArcGIS clients at for work a map asks for.

    Geometry service

    The geometry service ArcGIS clients signed in to this portal use for measuring, buffering and projecting — what Portal's clients read from it. Leave it empty to use this server's own. Name another, such as an ArcGIS Server's, and clients use that one instead; it answers them under its own sharing. ArcGIS Enterprise has this under Organization › Settings › Utility services › Geometry.

    General

    What this whole server does unless a service sets its own. What a map offers — basemaps, the ground under them, the geometry service clients use — is Studio's, under Organization › Settings.

    Query results

    How many features a query returns when it does not ask for a number, and the most it returns when it does — ArcGIS's maxRecordCount, which every service document gives. Larger pages mean fewer requests and heavier responses. A service that sets its own page size in its Parameters tab keeps it; empty here means the server's default.

    features

    Style sources

    Other servers a vector tile style may fetch tiles, fonts or icons from, such as a basemap vendor. A style is fetched by every viewer's browser, so only an administrator decides where it may send them. Write each as https://host, https://host:port or https://*.host for every name under a host. With none listed, a style may use only this server's own resources.

      Security

      How people sign in to this organization, and which apps may sign them in.

      Sign-in

      Where people can sign in besides a password on this server: an OpenID Connect or SAML 2.0 provider such as Microsoft Entra ID, AD FS, Keycloak, Okta or Google, or an LDAP directory such as Active Directory. Their groups there can decide their role and groups here.

      Apps

      Apps that sign people in to this server through OAuth — a web app with an app ID, or ArcGIS Field Maps. A person signs in on this server's own page, and the app receives a code only at an address registered here.

      Register an app

      An address must be https://, http://localhost, a custom scheme such as my-app://auth/, or urn:ietf:wg:oauth:2.0:oob. A code is never sent anywhere else.
