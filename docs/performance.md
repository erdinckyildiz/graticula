**Status:** STUB — not written

The performance model and its standing assumptions: millions of features,
billions of vertices, multi-terabyte raster collections, and the rule that data
never fits in RAM.

Records target latencies and throughputs per workload class, the measurement
methodology, and the link between each target and the benchmark that verifies
it. A target without a benchmark is an aspiration.
